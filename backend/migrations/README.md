# Alembic Database Migrations

This directory will contain Alembic migration files once initialized.

## Setup

```bash
cd backend
pip install alembic asyncpg

# Initialize alembic (first time only)
alembic init migrations

# Edit alembic.ini — set sqlalchemy.url:
# sqlalchemy.url = postgresql+asyncpg://postgres:postgres@localhost:5432/reverse_ai

# Edit migrations/env.py to use async engine and import all models:
# from app.core.database import Base
# from app.modules.auth.models import User
# from app.modules.video.models import Video
# from app.modules.dataset.models import Dataset
# from app.modules.annotation.models import Annotation
# from app.modules.training.models import TrainingJob
# from app.modules.inspector.models import InspectionResult
# target_metadata = Base.metadata
```

## Common Commands

```bash
# Generate a new migration from model changes
alembic revision --autogenerate -m "description of change"

# Apply all pending migrations
alembic upgrade head

# Roll back one migration
alembic downgrade -1

# Show migration history
alembic history

# Show current revision
alembic current
```

## Notes

- Never edit a migration that has already been applied to production.
- Always review autogenerated migrations before applying them.
- Keep migrations small and focused on a single schema change.
